The repository has configuration for Claude, ChatGPT, Mistral, Gemini, Cursor and other clients. Historical notes described some as privately installed or connected; those installation states and live-tool behavior were not independently verified during this registry pass and should not be interpreted as marketplace publication. IndexNow submissions, search indexing, and previously listed protocol endpoints likewise require separate live verification before claiming discovery or availability.

The official MCP registry manifest exists in `server.json` and `.mcp/server.json` of the skills repository; it must use `remotes[].type`, not `transport_type`. Correcting the manifest in Git is distinct from publishing it to the registry. The `agentum-mcp` and `agentum-langchain` packages are separate distributions with separate publication records.

Core [PR #1](https://github.com/Algiras/agentum/pull/1) merged as `476c4ee`; distribution [PR #1](https://github.com/Algiras/agentum-skills/pull/1) merged as `bd905e3`. The distribution reconciles both branch histories without force-pushing. [CI](https://github.com/Algiras/agentum-skills/actions/runs/41999869504) passed 12 SDK and 26 MCP tests and reached hosted `/health` with HTTP 200. Local health checks timed out, so those local failures are not evidence of a global outage. This health result does not prove the new core is deployed.

Hosted release remains gated on verifying an environment-preserving deployment route and publisher reuse terms for the direct sanctions feeds. The legacy release helper was not run because its payload can overwrite environment values. The official MCP registry stays at `0.2.0`; no updated hosted capability is claimed there.

The npm jobs returned success and explicit publication receipts for both new versions, with npm’s “being processed” notice. The first public registry check still returned the previous versions (`agentum-mcp@0.2.2`, `agentum-langchain@0.2.0`); public availability of the new versions is pending confirmation. Do not republish while npm processes them.
