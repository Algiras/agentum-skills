The repository has configuration for Claude, ChatGPT, Mistral, Gemini, Cursor and other clients. Historical notes described some as privately installed or connected; those installation states and live-tool behavior were not independently verified during this registry pass and should not be interpreted as marketplace publication. IndexNow submissions, search indexing, and previously listed protocol endpoints likewise require separate live verification before claiming discovery or availability.

The official MCP registry manifest exists in `server.json` and `.mcp/server.json` of the skills repository; it must use `remotes[].type`, not `transport_type`. Correcting the manifest in Git is distinct from publishing it to the registry. The `agentum-mcp` and `agentum-langchain` packages are separate distributions with separate publication records.
